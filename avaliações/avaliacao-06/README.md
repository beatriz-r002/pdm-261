# Avaliação 06 - Aplicação Flutter (Namer App)

Projeto desenvolvido para a disciplina de Programação para Dispositivos Móveis (PDM).

## 📌 Descrição
A aplicação foi construída seguindo as orientações do codelab oficial do Google:
👉 [Escreva seu primeiro app do Flutter](https://codelabs.developers.google.com/codelabs/flutter-codelab-first?hl=pt-br#0)

O aplicativo gera pares de palavras aleatórias, permite ao usuário curti-las/favoritá-las e visualizar uma lista com todas as palavras salvas na aba de favoritos.
